# Collabspace API

Backend REST API for **Collabspace** — a project-management and team-collaboration platform (projects, Kanban tasks, team chat, meetings with AI summaries, reports and an AI assistant).

Built with **Laravel 13** · PHP 8.4 · MySQL 8 · Sanctum · Reverb · Laravel AI.

> 🚧 Under active development — see the [roadmap](docs/ROADMAP.md) for progress.
